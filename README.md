# Agentic AI System – ReAct Architecture

Built a custom **Agentic AI system using Python and Groq's LLM API**, implementing the ReAct (Reasoning and Acting) framework to enable an LLM to reason through user queries, dynamically select tools, execute actions, and generate context-aware responses.

### Key Features
- **LLM Integration:** Integrated Groq's API to power the agent's reasoning and decision-making capabilities.
- **ReAct Framework:** Implemented a Thought–Action–Observation loop for iterative reasoning and tool execution.
- **Tool Calling:** Enabled the agent to identify and invoke relevant Python functions based on the user's query.
- **Custom Tools:** Developed tools such as a mathematical calculator and a planetary mass retrieval function.
- **Agent Execution Loop:** Built a custom execution loop to manage multiple reasoning iterations, process tool outputs, and determine when the agent has reached a final answer.
- **Dynamic Decision Making:** Enabled the agent to select appropriate tools based on the context of the query rather than relying on predefined execution sequences.

### Tech Stack
Python | Groq API | Large Language Models (LLMs) | Agentic AI | ReAct Architecture | Function Calling
